# Somewhere

A small, polished collection of games, built for Val. **Somewhere** offers countries, capitals, flags, shapes and land-connected border journeys on an interactive globe. **Something** offers General Trivia with hot streaks and perfect-round celebrations, plus the five-clue guessing game What am I. **Someone** offers Who am I, a five-clue game about 80 well-known people. **Somehow** is a branching geography/trivia adventure with hearts, supplies and a final boss.

**React + TypeScript + Vite, with an SVG globe powered by D3 Geo. Entirely static. No accounts, keys, backend, database, analytics, or runtime map APIs.**

## Run locally

Use **Node 22.12+** (Node 24 is also supported) and npm.

```sh
npm ci
npm run dev
```

Open the address printed by Vite. To run and check the deployable build:

```sh
npm test
npm run build
npm run preview
```

The `dist/` directory is the complete website. Keep its `assets/` and `data/` directories together. Do not open `index.html` directly from the filesystem; use a web server.

In the Codex cloud machine, npm’s default home cache is unavailable. Use `npm --cache /tmp/wep-app-npm ci` there. No secrets or environment variables are needed by the app.

## How it plays

- Use the **header wordmark dropdown** to switch between **somewhere.** (geography), **something.** (General Trivia and What am I), and **someone.** (Who am I), and **somehow.** (adventure). The word “some” uses the main text color; “where”, “thing”, “one”, and “how” use the theme accent. Someone opens Who am I, preserves your saved games, and uses the same switch animation and theme controls. Its people bank is lazy-loaded; opening Someone first does not load the globe, trivia pack or What am I bank. A brief full-screen accent sweep, turning compass and content fade accompany switching. Reduced-motion preferences switch immediately; enabling that preference during a transition finishes it immediately too. Your selected experience is saved locally, with a safe fallback when browser storage is unavailable. Geography rounds, search input and globe view stay intact when switching; celebrations continue uninterrupted. Opening a saved Something page loads no globe data until you visit Somewhere. No additional service or dependency is required.

- Use the header’s **sun/moon toggle** for light or dark mode. The first visit follows your device’s preference; your choice is saved in this browser and applied before the page paints on future visits. Dark mode covers search, history, dialogs, hints, errors and loading states, with readable heat labels and the same globe feedback colors. Dark-mode accents use mint green (`#62e99a`), including the logo, hearts, buttons and the softer green heart-wave background.
- The header’s **download icon**, immediately left of the light/dark control, checks for the latest deployed app. If the current build matches, it briefly says **You’re up to date**; otherwise it opens fresh app files. The icon is grey when no update is detected and green when an update is available, in either theme. An eight-second message below the header announces an available update on launch, returning to the app, or reconnecting; the green icon remains afterward. Automatic checks never reload a game, are limited to once per minute (except reconnects), and fail quietly offline. A manual failure offers a retry; checks time out after eight seconds. An update waits for all queued winning celebrations to finish, then reloads with a fresh HTML URL and content-hashed JavaScript/CSS. Saved rounds, trivia answers, mystery clues, selected modes and theme stay in local storage; the update does not clear website data or iOS system caches. This feature becomes available to an existing Home Screen install after it first loads a release containing the update button. Each build emits its matching `version.json`; deploy that file with the rest of `dist/`. No service worker, external update API or paid service is required.
- Choose **Countries**, **Capitals**, **Flags**, **Shapes**, or **Border Journey** in the dropdown above the search field. Each mode keeps a separate saved round, so you can switch without losing any journey. A random answer is selected once per round, and new rounds exclude that mode’s immediately previous answer. Country saves from the earlier version are migrated automatically.
- In country mode, search a name, ISO code, or alias such as `UK`, `UAE`, `Turkey`, or `Ivory Coast`. In capital mode, search a city name or spelling variant such as `Paris`, `Washington DC`, or `Kiev`; suggestions include the city’s country. Select a suggestion, then press **Make a guess**. With a keyboard, Enter selects the highlighted suggestion; a second Enter submits it.
- In **Flags**, identify the displayed flag image by guessing a country name or alias. Suggestions hide their flag images to avoid giving away the match. The globe, distances, heat, duplicate protection, closest-first history, reveal, and green answer animation work as in Countries. **Hint: reveal continent** shows a continent without using a guess, marking the map, or ending the round. The clue remains visible through refresh and mode switches, and resets with a new flag round. Used continent hints remain visible after completion.
- In **Shapes**, identify the country from its silhouette. The outline stays north-up and scales to fit the card, keeping islands and disconnected regions from the source together. **Hint: reveal continent** gives a clue without consuming a guess or ending the round. Shapes has its own saved answer, guesses and hint; the existing distance feedback, adjacency, globe animation, history, reveal and victory effects work as in Countries. Image errors offer **Try shape again** without losing progress.
- In **Border Journey**, travel from the visible starting country to the visible destination, crossing one shared land border per turn. Search and select the next country, then press **Cross the border**. Non-neighboring countries and the current country are rejected without consuming a crossing. Retracing your steps is allowed, so a detour cannot trap you. The chronological journey list and dashed globe route track your actual travels; tap any stop to refocus. The **Destination** button above the travel list centers the destination on the globe without consuming a crossing or ending the round. The current stop uses the theme accent, visited countries blue, and the destination gold until reached or revealed in green. Center-to-center arcs are a schematic guide, not literal border crossing locations. Routes are generated from an undirected border graph with a shortest starting distance of three to six crossings; disconnected islands are excluded. Finishing shows your crossing count and the shortest possible starting route length, without requiring an optimal route. **Give up and reveal answer** shows one shortest continuation from your last stop on the list and globe, ends the round without a celebration, and keeps your original route. Journey progress saves separately, including revisited countries. Invalid stored routes are rejected. A 1,000-crossing guard prevents oversized saves; at that limit, reveal the route to start another journey.
- Drag the globe to rotate it and pinch to zoom up to 32×. Map taps never select or submit guesses; all guesses go through the search interface. Keyboard users can focus the globe and use arrows, `+`, `-`, and `Home`.
- Each guess colors its country and displays the great-circle distance to the answer. Country and flag modes use representative country centers; capital mode uses the two cities’ coordinates and adds a marker for every guessed capital. Text labels and symbols supplement color.
- Cold: **7,000 km or more**. Cool: **3,000–6,999 km**. Warm: **1,000–2,999 km**. Hot: **under 1,000 km**. Countries sharing a land border—and capitals belonging to those countries—are marked **Adjacent** with the hottest, darkest-red feedback regardless of center distance. This does not count as a correct guess. Thresholds use unrounded distances; displayed kilometers are rounded.
- In the mystery modes, only an exact country or selected-capital match wins. A tiny nonzero distance is displayed as `<1 km`.
- In the mystery modes, guess history is sorted by unrounded distance for the selected mode, closest first, with original guess numbers preserved. The closest row has a highlighted background and a “Closest guess” badge; it stays pinned while the desktop list scrolls. Distance ties keep the original guess order. Tap a history entry to center it on the globe. Duplicate guesses are rejected. On phones, search sits above the globe; submitting a guess closes the keyboard and smoothly centers the globe on screen. After a short pause, the globe glides to your guess and zooms based on country area: smaller countries get a closer view, larger ones retain regional context. Automatic zoom ranges from 1.3× to 16×; manual controls reach 32×. Capital guesses use the area of their country while centering the city. Only after that movement finishes, the guessed country and any capital/tiny-country marker blink slowly in their heat color three times (about four seconds), then stay solid. A new guess, manual rotation, or resetting cancels the previous cue. Reduced-motion preferences skip both movement and blinking. Correct guesses and revealed answers blink green. Correct answers launch their victory effect immediately when submitted, independently of the globe’s movement and green blink; no result popup opens.
- **A heart for Val:** hold the heart next to “Built for Val” for about two-thirds of a second. It beats, then a warm wave spreads from the heart across the background in the logo’s accent (orange in light mode, mint green in dark mode) and fades back after a moment. Release after it starts and it will finish on its own. Keyboard users can focus the heart and hold Space or Enter. Short taps and canceled holds leave the game alone. Reduced-motion preferences use a still, subtle tint.
- The **Give up and reveal answer** button is below the guesses and above the footer. It ends the current mode’s round, reveals the answer on the globe in green, and preserves the guess history. The reveal uses the same size-aware zoom. After the globe arrives, the answer and its marker blink three times, then stay green. It does not add a winning guess or count as a win, and it works before any guesses. Other modes are unaffected.
- Correct guesses in all five Somewhere modes get one of six full-screen victory effects: **Confetti shower**, **Fireworks**, **Emoji parade**, **Heart fountains**, **Shooting stars**, or **Rainbow bubbles**. A shuffled bag shared across modes uses all six before reshuffling and prevents an immediate repeat at the boundary. Effects begin immediately on a correct guess (or as soon as an earlier queued effect finishes), last 4.8 seconds of visible playback, and leave controls clickable. Wrong guesses, give-up reveals, refocusing a history row, and refreshing a completed game do not launch effects. Starting another round, resetting the map, switching modes, making guesses or earning another win does not cancel or restart an active celebration. Additional wins queue and play in order, each for its full duration. Globe loading, rotation, zoom and blinking never delay or cancel the celebration. Hiding the tab pauses playback until you return; enabling reduced motion during an effect pauses it until motion is allowed again. Players who already prefer reduced motion when guessing correctly get the static win screen. The transient queue ends when the page is refreshed or closed; saved rounds remain intact. Emoji parade uses standard celebration/heart/globe emojis, with no flag emoji dependency.
- A completed round keeps the answer, guess count, replay controls, and copy-result button on the page, without a popup. Finish by guessing correctly or revealing the answer, then choose **Explore another round** to begin a new journey. **How to play** is in the footer.
- All five Somewhere rounds, all guesses, the selected mode, and revealed/completed states are saved in this browser’s `localStorage`. Invalid saves recover with a message. If storage is disabled or full, gameplay continues with a warning. Progress is local to the browser and is not synced between devices or tabs.

### Something games

**General Trivia** has ten questions per round, four choices each and no timer. Choose once, read the explanation, then press **Next question**. The current question, shuffled choices, score and feedback survive refreshes. A sidebar records answers; expand an entry to review its question and explanation. The score screen offers **Play another round**. The bundled pack currently contains 400 original-worded questions, with 40 in each of ten categories: animals, space, science, food and drink, history, arts and books, film and music, nature, the human body, and games/everyday things. Stable general-knowledge facts are used rather than current rankings or breaking news; the pack is manually maintained, so factual corrections can be made in `src/data/trivia.ts`. No external trivia API, account, paid service or runtime content request is required.

Correct answers use the six existing celebrations until three consecutive correct answers. At **3+**, the sidebar says **On Fire** and correct answers launch **Fire streak**: fire emojis rise across the screen with progressively greater count, size and speed on each streak continuation. Counts range from 28 to 56 on phones, or 42 to 84 on desktop, over streaks 3–10. A wrong answer resets the count to zero; the next correct answer returns to the usual six effects. A new round also resets the streak. A **10/10 perfect round** additionally queues **Perfect round**, a golden starburst with expanding rings and a trophy, after the final answer's fire effect. All celebrations share the same queue as Somewhere: 4.8 seconds of visible playback per effect, no cancellation on new rounds, wrong answers, mode switches or experience switches. Already queued effects finish even after a wrong answer resets the current streak. Reduced-motion preferences keep results static; existing hidden-tab and live reduced-motion pause/resume apply to fire and trophy effects too.

**What am I** starts with one clue about an animal, object, structure or natural phenomenon. **Reveal another clue** uncovers progressively clearer clues, up to five, without spending a guess. Type an answer and press **Make a guess**; capitalization, accents, punctuation, leading articles and listed aliases are normalized. Wrong guesses remain visible and do not end the mystery. Duplicate normalized guesses are rejected. **Give up and reveal answer** remains below the guesses; it reveals the solution and all clues without creating a win or celebration. A correct answer uses the usual six celebrations. After solving or revealing, **Try another mystery** starts a different answer. There are 80 original five-clue mysteries in `src/data/mysteries.ts`. Clues may intentionally fit several things at first; later clues narrow the intended answer. Specific aliases are accepted rather than unrestricted fuzzy matching.

Each Something mode has an independent saved session (`something.trivia.v1`, `something.mystery.v1`) and shares `something.mode.v1` for the selected mode. Sessions validate question IDs, choice permutations, answer counts, clue bounds, aliases and terminal states before loading. Damaged saves recover only the affected mode with a notice; storage failures leave games playable with a warning. New rounds prioritize unseen content and exclude the immediately previous question set or mystery; content eventually repeats after the finite local pack is used. Both modes retain their UI state when switching experiences. Opening Something first does not load the globe, and Something's question/clue module is lazy-loaded when first visited. Answers are bundled in a static app and can be inspected; this is a private, trust-based game rather than an anti-cheat system. **How to play** in the footer explains the selected experience.

### Someone — Who am I

Choose **someone.** in the header to play **Who am I** immediately. The first collection contains **80 distinct real public figures**, with ten each in science and mathematics, music, screen and stage, sport, art and literature, history, exploration and invention, and changemakers. Original clue sets and short explanations live in `src/data/people.ts`. No portraits, paid APIs or external trivia service are required. The clues focus on public achievements and become more specific as you reveal them.

Start with one broad clue, reveal up to five progressively clearer clues for free, and type a name. Full names and curated aliases (such as Einstein, Beyoncé, Pelé or The Rock) accept case, accent, punctuation and spacing variations. Some unique surnames and commonly used nicknames are accepted; unrestricted fuzzy matching and ambiguous first names are not used. Wrong guesses remain visible without ending the game, and normalized duplicates do not count twice. **Give up and reveal answer** sits below the guesses and reveals the person, explanation and all clues without a celebration. Correct guesses immediately use the existing six winning animations. **Try another person** starts a fresh mystery; new rounds prioritize all unseen people before recycling and never immediately repeat the last person.

Progress saves independently under `someone.who.v1`, including the person, guesses, clues, completion and seen-person history. Switching experiences retains an unfinished name in the input. Invalid saves recover only Who am I with a notice; blocked storage leaves the game playable with a warning. Refreshing a completed round never replays a celebration, and queued celebrations continue through new rounds or experience switches. The footer’s **How to play** explains this experience. Who am I and What am I share the tested clue-game engine in `src/lib/mystery.ts`; their content and saved sessions stay separate. Somehow keeps using the original What am I collection.

### Somehow adventure

Choose **somehow.** in the header to play immediately. No password, account, backend or paid service is required.

A run has **thirteen stops**, displayed as a 31-node branching map. Each of the three route sections has three rows of three choices. Only highlighted, connected nodes can be selected. Choose between normal challenges, shops, discoveries and harder elite trials; three guaranteed rest stops occur at stops four, eight and twelve. Clear the final boss at stop thirteen to win. Starting hearts: **3/3**; maximum containers: **5**. Rest stops restore one heart without raising the maximum. A run ends when the last heart is lost without a Phoenix feather, or when the final battle is abandoned. The completed/failed stop stays on screen; use **Return to the route** to continue. Rewards cannot be collected twice.

- **General Trivia:** answer two of three questions correctly. A failed trial risks one heart, rather than charging for every wrong answer.
- **Elite trial:** two correct answers in a row. **Final boss:** three in a row. Each wrong answer resets the streak and risks one heart. Read each explanation before continuing; no timer is used.
- **Countries, Capitals, Flags, Shapes:** the existing search, aliases, distances, adjacency feedback, guess history, country images and interactive globe, with eight guesses per encounter. Early target selection excludes very small and exceptionally large countries. Exact correct guesses clear the encounter; exhausting the budget or giving up reveals the answer and risks one heart. Guesses are never made by tapping the globe.
- **Border Journey:** the existing mainland-only border graph, with an initial route three to six crossings long and a budget of the shortest starting route plus four crossings. Retracing is allowed; invalid crossings do not consume the budget. The Trail compass names a valid next step toward the destination.
- **What am I:** five guesses, useful aliases and five progressively revealing clues. Extra clues are free. A Trail compass gives the first letter and, if possible, another clue. Invalid/duplicate guesses never consume a turn.
- **Shops:** one of each purchasable item per visit, paid with run coins. Lucky stars are never sold, even if you already own one. Buying and using are separate actions. **Discoveries:** choose a supply item plus ten coins or restore one heart. **Rest stops:** restore one heart up to the current maximum.

Relevant supplies appear directly on each active trial as **Use [item] (quantity)** buttons: trivia offers 50/50 and question rerolls; geography and mysteries offer a compass and extra guesses. Healing, containers, protection and Lucky stars also appear when relevant and stocked. Used or temporarily unavailable items are disabled. **Satchel** shows only owned items and their descriptions, including passive Phoenix feathers. Items with zero stock disappear, and an empty satchel shows where to find more supplies. Unavailable uses explain why and never consume stock. Flags/shapes retain one image and one continent hint when a compass is used.

| Item            | Effect                                                                               | Shop price |
| --------------- | ------------------------------------------------------------------------------------ | ---------- |
| Heart tonic     | Restore one heart                                                                    | 8          |
| Heart container | Add and fill one container, up to five                                               | 25         |
| 50/50 lens      | Remove two wrong options from this unanswered trivia question                        | 12         |
| Lucky star      | Auto-win one non-boss challenge; never usable on the final boss                      | Found only |
| Heart shield    | Arm protection against the next lost heart                                           | 10         |
| Trail compass   | Geography continent, next land crossing, or mystery initial/clue; once per encounter | 8          |
| Second wind     | Two extra geography/mystery guesses; once per encounter                              | 8          |
| Fresh page      | Reroll an unanswered trivia question without resetting score or streak               | 10         |
| Phoenix feather | Automatically revive with one heart when the last would be lost                      | 35         |

Every new run starts with **three hearts**, **25 coins**, **one Heart tonic**, **one 50/50 lens** and **one Trail compass**. Normal challenge wins earn **6 coins**, elite trials earn **10**, and the final boss earns **15** (previously 20/35/50). Shop prices and starting coins stay unchanged; discoveries still offer a supply item plus ten coins or healing. There are no developer controls, free refills or testing shortcuts. Lucky stars can only be found in discoveries or as a **10% drop after a non-boss challenge cleared without a star**. Star-assisted clears, failed trials, shops, rests and the final boss never roll for a star. A found star is added once, saved immediately, and announced in the reward message. Inventory is capped at 99 per item. Stars cannot be used on the boss, including stars carried over from an older save.

Challenge clears share the existing six celebrations. Boss victories queue the fire effect followed by the golden trophy/star celebration. The global animation queue continues through restarts and experience switches, and updates wait for it to finish. Runs and all inventory/route/encounter state save separately under `somex.run.v1` (legacy storage key retained after the rename; current schema version 3); invalid saves recover only this adventure. Both earlier save layouts upgrade automatically, keeping inventory, coins, progress and the active encounter. New route nodes already behind an active/completed boss are marked as carried-over progress so no one is sent backwards or loses a completed victory. Runs still before the boss get the additional section ahead. Older boss victories cleared using a Lucky star remain completed, while every active boss follows the new restriction. Standalone game progress is independent. No automatic celebration replays on refresh. Somehow loads its adventure/questions when first visited and its globe only for geography encounters. Duplicate SVG and history IDs are namespaced when two geography views are retained in the page.

Daily challenges are deliberately deferred; replayable random rounds cover the core experience without timezone rules or additional infrastructure.

## Deploy free: Cloudflare Pages

Cloudflare Pages serves this app as static files with HTTPS and a free `pages.dev` address. There is no custom domain requirement and no game server to run. Hosting and build quotas remain subject to the provider’s current free-plan terms; the app itself makes no metered map or country API calls.

1. Commit this project and push it to your GitHub repository, `dlc-diego/somewhere`. The initial checkout was empty; the full application must be present on the connected branch before deployment.
2. Sign in to Cloudflare and create a **Pages** project connected to that Git repository. Choose the branch containing the app (normally `main`).
3. Configure:

   | Setting                | Value                                                    |
   | ---------------------- | -------------------------------------------------------- |
   | Framework              | Vite (or no preset with the settings below)              |
   | Root directory         | Repository root                                          |
   | Build command          | `npm run build`                                          |
   | Build output directory | `dist`                                                   |
   | Node version           | Set `NODE_VERSION` to `22` or `24` in the build settings |

4. Deploy. The platform installs dependencies and builds the project. Open its assigned HTTPS URL on your phone and computer.
5. Verify the globe loads, make a guess, refresh to check persistence, and start another round. Share the assigned URL with your wife.

Future pushes to the connected production branch rebuild the site. There are no runtime secrets to enter. The app includes responsive layouts, a mobile viewport declaration, touch rotation and pinch gestures, and 16px mobile inputs to avoid focus zoom on iOS. A phone needs a current browser with JavaScript enabled.

## Deploy free: GitHub Pages (simplest with this repository)

A deployment workflow is included at [.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml). GitHub Pages availability for private repositories depends on your GitHub plan; Cloudflare Pages is a useful alternative if you want the source repository to stay private.

1. Push the app to `main` in your GitHub repository.
2. In the repository’s **Settings → Pages**, choose **GitHub Actions** as the deployment source.
3. In **Actions**, run **Deploy to GitHub Pages**, or push another commit to `main`.
4. Wait for the deployment job to succeed, then use the URL provided by GitHub Pages (typically `https://dlc-diego.github.io/somewhere/`).

Vite’s relative base (`./`) and relative map-data paths support both domain-root hosting and the `/somewhere/` project path. No client-side router or rewrite rules are needed. The app’s nested-path loading is covered by a browser test.

### Netlify alternative

Import the Git repository, set build command `npm run build`, publish directory `dist`, and use Node 22 or 24. Netlify provides an HTTPS `netlify.app` address. Review its current free-plan credits and limits before choosing it. No functions or paid add-ons are required.

## Data, accuracy, and licensing

- **Playable list:** 195 entries: 193 UN member states plus Palestine and Vatican City. This is an explicit gameplay scope, rather than a statement about sovereignty. Dependent territories and other disputed states, including Taiwan and Kosovo, are not answers in this version. The guide explains this scope before play.
- **Metadata:** [mledoze/countries](https://github.com/mledoze/countries), provided by `world-countries`. Each playable country has a canonical ISO 3166-1 alpha-3 identifier. Names and useful aliases are normalized for case, diacritics, punctuation, and whitespace. The two Congos have distinct display names.
- **Adjacency:** Shared land borders are generated from `world-countries` ISO alpha-3 border lists, made symmetric, and restricted to playable countries. Explicit territory mappings include French Guiana/Saint Martin → France, Sint Maarten → Netherlands, Gibraltar → United Kingdom, and Hong Kong/Macau → China. Canada–Denmark’s 2022 Hans Island land border is added; the source’s one-sided India–Sri Lanka entry is removed because Palk Strait is not a land border. Sea crossings and maritime borders alone do not count. The graph follows source border claims elsewhere and is independent of simplified map geometry.
- **Shapes:** All 195 silhouettes are generated offline from the per-country GeoJSON outlines in the existing `world-countries` dependency, credited to [mledoze/countries](https://github.com/mledoze/countries) and its thematicmapping.org boundary source. They use a north-up local azimuthal equal-area projection, corrected exterior winding and a 0.25-pixel projected simplification tolerance. Every island remains represented; disconnected regions are not rearranged or resized separately. Each country is scaled to the same card size, so shape size is not a clue to land area. Tiny atolls may be difficult to identify. Generalized, historical outlines and overseas-territory choices can differ from the globe (for example, the France silhouette emphasizes European France and Corsica rather than French Guiana). Disputed boundaries follow the upstream dataset. The adapted path database is downloadable at `public/shapes/outlines.json`, with attribution and the ODbL license beside it. Run `npm run data:shapes` to regenerate just these images, or `npm run data:generate` for all geographic assets. SVG clues are self-hosted and fetched one at a time; no shape API or map-rendering work runs during gameplay. Accessible image labels remain neutral until completion; this is a visual recognition game, and the same browser-only answer-privacy limits apply.
- **Flags and continent hints:** Flags use bundled 4:3 SVG images from [flag-icons](https://github.com/lipis/flag-icons), pinned as a development dependency and copied to `public/flags/<ISO-alpha-3>.svg` by the data generator. Only the 195 playable images are included, with the upstream MIT license in `public/flags/LICENSE.txt`. Images load from the same static site, not a third-party CDN or API, so they display independently of device emoji support. A failed challenge image offers a retry without resetting the round or hint. Some flags (such as Chad and Romania) remain very similar; only the exact country wins, and continent/distance clues can help. Screen readers get a neutral “Mystery flag” label until completion so the accessible name does not disclose the answer; this remains a visual recognition game. Continents follow the metadata’s region classification, with the Americas split using subregion: South America stays South America; Central America, the Caribbean and North America use North America. Oceania is the regional continent label. Transcontinental countries use one classification (Russia → Europe; Türkiye → Asia); overseas territories do not change the hint.
- **Capitals:** One selected capital/government seat per playable country, using representative public-domain Natural Earth populated-place coordinates joined to canonical country IDs. Choices include Pretoria (South Africa), Sucre (Bolivia), Amsterdam (Netherlands), Mbabane (Eswatini), Sri Jayawardenepura Kotte (Sri Lanka), and Ramallah as Palestine’s administrative seat. Yaren is Nauru’s government district, not an official capital, and uses a documented approximate point. Other co-capitals are not separate answers; aliases refer to the same selected city. The source can lag relocations (for example Jakarta follows the source during Indonesia’s transition). See [capital source notes](scripts/data/README.md) for the full policies, source details, and exceptions. City markers identify actual city points rather than country centers.
- **Boundaries:** Natural Earth 1:50m via [world-atlas](https://github.com/topojson/world-atlas). Country features are joined through zero-padded ISO numeric codes and then matched to alpha-3 records; names are never used for matching. MultiPolygon features preserve disconnected regions. Some dataset IDs repeat across associated regions; rendering uses separate feature keys while matching all their parts to the same country.
- **Rendering:** The generator simplifies topology, preserving shared borders and disconnected polygon records. Outlines are approximate and small islands may be visually reduced or degenerate at this scale. Tiny guessed countries receive a center marker; Tuvalu, which has no boundary in this dataset, always receives one. Before guessing, tiny countries can be selected reliably through search.
- **Disputes:** Borders reflect the source dataset’s choices and vintage. Areas without a matching numeric code remain neutral and unplayable. Claims, overseas dependencies, and disputed areas are not reassigned by inference from their labels.
- **Centers and distance:** Metadata supplies representative latitude and longitude, which are not calculated land centroids, capitals, or nearest border points. The same coordinates are used consistently for all guesses and answers. Large or island countries can produce unintuitive center distances; overseas regions do not change the chosen center. Haversine uses mean Earth radius **6,371.0088 km**, handles the date line and poles, and clamps floating-point error. The Earth is treated as a sphere.
- **Licenses:** Natural Earth geography is public domain; the `world-atlas` package has an ISC license. Country metadata is ODbL. The adapted metadata database is distributed under ODbL at `public/data/countries.json`, alongside the complete license. Flag images are MIT-licensed; their attribution and full license are shipped with the site. Original sources and download links are credited in the game guide. No assets, branding, or code were copied from Globle.

Generated datasets are committed, bundled, and served from your site. Updating npm dependencies does not silently change geography. To deliberately update them:

```sh
npm run data:generate
npm test
npm run build
```

Review the resulting data changes and attribution. `scripts/generate-data.mjs` is deterministic and validates list membership. Routine builds use committed data and do not need to regenerate it.

## Architecture and trade-offs

See [docs/technical-plan.md](docs/technical-plan.md) for the library comparison and implementation choices.

```text
src/
  lib/            Country lookup, geographic math, game rules, saved-state validation
  components/     Globe, accessible country/capital search, guess history, native dialog
  data/           Playable countries, selected capitals, and border metadata
  App.tsx         Round state and the game screen
  styles.css      Responsive plain CSS and reduced-motion support
public/data/      Lazy-loaded boundaries, adapted metadata, attribution licenses
scripts/          Reproducible dataset preparation
tests/            Browser tests using production assets
```

**Answer privacy:** The globe receives guesses and only receives the answer location after the player explicitly gives up; correct guesses already appear in the guess list. It does not pan to or mark an answer before a correct guess or giving up. However, a fully static game must calculate distances in the browser, so the answer exists in memory and saved storage. A player using developer tools can find it. Obfuscation would not solve this. Strong secrecy requires a server to hold the answer and evaluate guesses; that complexity is intentionally avoided for this personal game.

**Performance:** Country boundaries and D3 are loaded separately from the initial game UI. Search works while the map loads and after map failures. Geometry is simplified ahead of time. A bundled Web Worker projects country outlines away from the UI thread, skipping offscreen shapes and obsolete camera frames. Paths, markers and ocean zoom update together, and the heat blink waits for the final displayed frame. If workers are unavailable, rendering falls back to the main thread. There is no animation/render loop when idle, and no remote imagery or web fonts. Victory effects use a short-lived canvas with a capped pixel ratio and particle count; no animation runs after the effect completes. SVG is a shaded orthographic projection with 3D-like rotation, not a WebGL 3D scene. Current measurements and limits are recorded in the technical plan.

Once GitHub Pages is configured to use GitHub Actions, pushes to `main` automatically rebuild and deploy the site. The deployment workflow reports its published URL. A local build alone does not publish the app.

Zoom framing uses an area-based estimate, not a guarantee that every island or elongated border fits on screen. Zooming magnifies the bundled Natural Earth boundaries; it cannot add detail absent from that data. Tiny-country markers remain visible, and reset restores the full globe. Manual zoom cancels an active flight or blink.

### Border Journey geography

Border Journey uses the same ISO alpha-3 country IDs and `world-countries` border metadata, with a separate reviewed mainland-only filter in `src/data/journey-border-exclusions.json`. Generation, submitted crossings, shortest-route reveals and saved-route validation all use this one filtered graph. Every new route stays within the connected **Americas** or **Africa–Eurasia**. Europe–Asia and Egypt–Israel crossings remain possible because they do not require an ocean jump; North America–Europe routes are impossible.

The mode treats each country as one primary connected land area: European France, mainland Spain, Great Britain, mainland Russia, mainland Azerbaijan, mainland Angola, the main connected Croatian area, peninsular Malaysia and Java for Indonesia. It excludes overseas borders (Canada–Denmark through Hans Island, France–Brazil/Suriname through French Guiana, France–Netherlands through Saint Martin, Spain–Morocco through Ceuta/Melilla, Spain–UK through Gibraltar), borders requiring detached exclaves (Kaliningrad, Nakhchivan, Cabinda and the Dubrovnik coastal area), Northern Ireland links and Borneo/New Guinea/Timor island shortcuts. Indonesia has no eligible border on Java, so it is not selected for journeys. Malaysia uses a journey-only point at 4.2° N, 102.1° E on its peninsula for camera focus, markers and route arcs, replacing its usual Borneo-centered point only in this mode. Other modes retain their existing political adjacency feedback. Existing journey saves that depend on excluded crossings or disconnected endpoints recover to a fresh journey with the standard warning; other saves are preserved.

Borders along rivers and canals are still land borders; sea bridges, tunnels and ferries do not create new graph edges. The displayed arcs join representative country centers and are schematic, not literal walking directions. Border claims follow the source metadata, and this remains a geographic puzzle rather than a claim about legal or practical travel access. Review the exclusion list whenever updating the source border data.
